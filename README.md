# 🎬 Movie Recommendation System

A modern Movie Recommendation System built with **React.js**, **Tailwind CSS**, and the **TMDB API**. Users can discover trending movies, search for films, browse by genres, view detailed movie information, watch trailers, and manage a personalized watchlist.

## 🚀 Features

* 🔍 Search movies by title
* 🔥 View trending movies
* 🎥 Browse popular movies
* ⭐ Explore top-rated movies
* 📅 Check upcoming movie releases
* 🎭 Filter movies by genre
* 📖 Detailed movie information page
* ▶️ Watch official movie trailers
* ❤️ Add and remove movies from watchlist
* 💾 Watchlist stored using Local Storage
* 📄 Load more movies with pagination
* 📱 Fully responsive design using Tailwind CSS

## 🛠️ Tech Stack

### Frontend

* React.js
* React Router DOM
* Tailwind CSS
* Axios

### APIs

* TMDB (The Movie Database) API

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/movie-recommendation-app.git
```

### 2. Navigate to the project directory

```bash
cd movie-recommendation-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create a .env file

```env
VITE_TMDB_API_KEY=YOUR_TMDB_API_KEY
```

### 5. Start the development server

```bash
npm run dev
```
